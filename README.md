# CV Generator


## Getting Started

### Prerequisites
1. Install **docxtpl** by running `pip install docxtpl`
2. Install Libre Office: https://www.libreoffice.org/download/download-libreoffice/
3. Add Libre Office executable path (`C:\Program Files\LibreOffice\program\`) to Path
4. Make sure VsCode uses the correct interpreter (`python --version` vs `CTRL+SHIFT+P -> Python:Select Interpreter`)

### Quick Start
Running the app: `python generate.py`
